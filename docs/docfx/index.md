# ResumeBuilder — документация API

Справочник сгенерирован инструментом **DocFX** из XML-комментариев библиотеки `ResumeBuilder.Core`.

Самые подробно описанные классы (с параметрами, возвращаемым значением, исключениями и примерами):

* `ResumeBuilder.Core.Services.TextHelper` — проверка и поиск данных регулярными выражениями;
* `ResumeBuilder.Core.Services.ReportCalculator` — подсчёт сводного отчёта;
* `ResumeBuilder.Core.Validation.ResumeValidator` — проверка резюме.

Откройте раздел **«Справочник API»** в меню сверху.
