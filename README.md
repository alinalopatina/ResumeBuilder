# ResumeBuilder — конструктор резюме с экспортом в PDF и QR-кодом

Курсовой проект по дисциплине «Конструирование программного обеспечения».
Автор: Лопатина Алина Николаевна, БНТУ, ФИТР, гр. 10701224.

## Что умеет программа

- заполнение резюме: личные данные, о себе, опыт работы, образование, навыки;
- экспорт в **PDF с QR-кодом** (визитка vCard), в Word и Excel;
- сводный отчёт (Excel + Word + txt) и печать;
- сохранение в JSON и в двоичный файл;
- проверка введённых данных, русский и английский интерфейс.

## Как запустить

1. Visual Studio 2022/2026 с компонентом «Разработка классических приложений .NET».
2. Открыть `ResumeBuilder.sln`.
3. Сделать `ResumeBuilder.Wpf` запускаемым проектом и нажать F5.

Библиотеки скачиваются из NuGet автоматически.

## Структура

```
src/ResumeBuilder.Core    — библиотека классов: модели и логика (сохранение, экспорт, проверка)
src/ResumeBuilder.Wpf     — интерфейс на WPF по шаблону MVVM (Views, ViewModels)
tests/ResumeBuilder.Tests — модульные тесты xUnit
```

## Библиотеки

QuestPDF (PDF), QRCoder (QR-код), ClosedXML (Excel), DocumentFormat.OpenXml (Word), Serilog (журнал), xUnit (тесты).
