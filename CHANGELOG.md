# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.5.0] — 2026-11-10

### Добавлено
- Архитектура решения: Core / Infrastructure / Wpf / Cli / Tests.
- Модель резюме, паттерны Builder, Memento, Template Method, Strategy.
- Сериализация: JSON и собственный двоичный формат `.rbin`, автосохранение, сохранение настроек окна.
- Экспорт в PDF с QR-кодом (шаблоны Classic и Modern, маскирование контактов).
- Экспорт в Word и Excel, обратный импорт таблицы опыта из Word, замер производительности экспорта.
- Сводный отчёт в Excel, Word, PDF и TXT из одной агрегации.
- Печать резюме через системный диалог.
- Журналирование Serilog: консоль, файл, JSON, аудит, ротация, CorrelationId, медленные операции.
- Локализация интерфейса ru/en без перезапуска, культурно-зависимое форматирование.
- Регулярные выражения: «умная вставка», нормализация телефонов, маскирование, lookaround.
- Валидация: ручная, DataAnnotations, собственные атрибуты, отчёт по полям.
- Unit-тесты xUnit, сборка в GitHub Actions.
