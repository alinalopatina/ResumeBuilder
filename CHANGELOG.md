# Журнал изменений

Все заметные изменения проекта записываются в этот файл.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
номера версий — [семантическое версионирование](https://semver.org/lang/ru/):
`МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ` (новые функции увеличивают минорную, исправления — патч-версию).

## [Не выпущено]

### Добавлено
- Конфигурирование: настройки из кода, `appsettings.json`, профилей Development/Production,
  личного файла пользователя, переменных окружения `RESUMEBUILDER_*` и аргументов командной строки.
- Окно «Настройки…»: папка экспорта, размер QR-кода, автосохранение, основной цвет, импорт/экспорт, сброс.
- Проверка настроек при запуске и применение изменённого файла настроек без перезапуска.
- Автосохранение черновика по таймеру.

### Изменено
- Язык, выбранный в меню, хранится в личных настройках (`usersettings.json`), а не в `settings.json`.

### Запланировано
- Сборка установщика и Docker-образа (лабораторные 10.1–10.3).

## [1.1.0] — 2026-11-16

### Добавлено
- Заполнение контактов из текста старого резюме (e-mail, телефон, сайт, дата рождения)
  с помощью регулярных выражений; программа сообщает, какие поля уже были заполнены.
- Окно «Просмотр отчёта» со сводной статистикой и печатью.
- Сравнение размера и скорости JSON и двоичного формата (меню «Файл»).
- Проверка повторяющихся навыков при валидации резюме.
- Тесты на исключительные ситуации и время выполнения, документ `docs/testing.md`.
- Документация: CONTRIBUTING.md, GLOSSARY.md, генерация справочника API через DocFX.

### Исправлено
- Программа падала при запуске на Windows ARM64 (`TypeInitializationException` в QuestPDF):
  теперь на ARM собирается x64-версия.
- При повторном импорте опыта из Word появлялись дубликаты мест работы.

## [1.0.0] — 2026-11-10 — первый релиз

### Добавлено
- Решение из трёх проектов: библиотека `ResumeBuilder.Core`, интерфейс `ResumeBuilder.Wpf` (MVVM),
  тесты `ResumeBuilder.Tests`.
- Редактор резюме: личные данные, о себе, опыт, образование, навыки.
- Экспорт в PDF с QR-кодом (vCard), в Word и Excel; сводный отчёт; печать.
- Сохранение в JSON и собственный двоичный формат, настройки окна.
- Проверка данных: ручная и через атрибуты DataAnnotations.
- Журналирование Serilog: консоль, файлы, JSON, аудит, CorrelationId.
- Русский и английский интерфейс.
- Документы README, LICENSE (MIT), XML-комментарии в коде.
